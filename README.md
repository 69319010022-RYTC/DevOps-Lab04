# DevOps-Lab04: GreenFix IT Support

## คำอธิบายโปรเจกต์

โปรเจกต์นี้เป็นหน้าเว็บไซต์ตัวอย่างสำหรับบริการ **GreenFix IT Support** ซึ่งนำเสนอการช่วยเหลือด้านไอทีสำหรับองค์กร เช่น การซ่อมคอมพิวเตอร์และอุปกรณ์สำนักงาน การจัดการบัญชีผู้ใช้และความปลอดภัย รวมถึงการแก้ไขปัญหาเครือข่าย

หน้าเว็บแสดงข้อมูลบริการ ขั้นตอนการรับแจ้งและติดตามปัญหา ตัวอย่างสถานะ Ticket สถิติการให้บริการ รีวิว และช่องทางติดต่อ โดยออกแบบเป็นภาษาไทยและรองรับการแสดงผลบนหน้าจอขนาดเล็ก

## เทคโนโลยีที่ใช้

- HTML สำหรับโครงสร้างเนื้อหา
- CSS ภายใน `index.html` สำหรับรูปแบบ สี การจัดวาง และการรองรับหน้าจอหลายขนาด

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้งแพ็กเกจหรือเริ่มเซิร์ฟเวอร์

## ขอบเขตของต้นแบบ

เว็บไซต์นี้เป็นหน้าเว็บสาธิตแบบ static ปุ่มเข้าสู่ระบบ แจ้งปัญหา แจ้งซ่อม และติดต่อยังไม่ได้เชื่อมต่อกับระบบหลังบ้าน จึงยังไม่สามารถส่งคำขอหรือจัดการ Ticket ได้จริง ข้อมูลสถิติ สถานะ Ticket และรีวิวเป็นเนื้อหาตัวอย่าง
